# EpoxyManager エポキシ樹脂ワークステーション

> 良工まずその刀を利くし、能書は必ず好筆を用う  
> エポキシ向けに調整；他の熱硬化性 / UV硬化型 / PU 系配合にも応用できる可能性あり

[繁體中文](README.zh-TW.md) · [English](README.md) · **日本語**

**エポキシ接着剤・封止剤の配合設計**のためのデスクトップワークステーション。機械学習による粘度予測、材料データベース管理、完全な 4 言語対応を備えています。

---

## ✨ 主な機能

### 🧪 配合設計
- **1K 一液型**配合設計：`target_100g` / `phr_100` / `free` の 3 種類のバランスモード対応
- **2K 二液型**配合設計：当量比に基づく A / B 剤計算、EEW / AHEW による当量バランス、カスタム配合比率
- リアルタイムコスト計算、塩素含有量追跡、仕込み補正
- Excel への一括コピー（縦 / 横レイアウト対応）

### 📊 機械学習による粘度予測
- **5 層アンサンブルモデル**：Gaussian Process Regression + Bayesian Ridge + 適応 k-NN
- 物理モデルによるフォールバック：Grunberg-Nissan 混合則、Arrhenius 温度依存性、Krieger-Dougherty フィラー補正
- Jaccard 類似度による過去配合の重み付け補正
- 粘度データ付き配合が 2 件以上蓄積されると自動的に有効化

### 🧮 化学計算ツールボックス
- **ゲル化時間推定**：Arrhenius 外挿により 7 種類の硬化剤に対応（DICY / アミン / 酸無水物 / イミダゾール / メルカプタン / 潜在性 / フェノール）
- **DiBenedetto Tg 予測**：モノマー Tg₀ / Tg∞ と硬化度から算出
- **CTE 予測**：フィラー体積分率を用いた混合則
- **UV / 熱デュアル硬化**設計：光開始剤 + 熱開始剤のバランス
- **DSC 解析**：Ti / Tp / ΔH / Ea 抽出、触媒ホモ重合係数
- **熱バランス計算**：断熱温度上昇、放熱推定

### 🌏 完全多言語対応
- ホットスワップ可能な言語切替：**繁體中文 / 简体中文 / English / 日本語**
- 596 個の翻訳キーで UI 要素、物性名、試験法、ツールチップを完全網羅
- 言語切替時も CSV 互換性を維持

### 🎨 Apple スタイル UI
- 9 色のテーマカラー（ブルー、バイオレット、ピンク、レッド、オレンジ、グリーン、シアン、グラファイト、ブラック）
- カスタム丸角ドロップダウン、ツールチップ、セグメントボタン
- システムフォント自動検出（SF Pro / Yu Gothic / Hiragino）

### 📦 材料・配合データベース
- 8 カテゴリー、80+ の定義済み物性項目（未硬化 / 硬化過程 / 機械 / 熱 / 耐薬品 / 電気 / 信頼性 / カスタム）
- カスタム材料カテゴリー（樹脂、硬化剤、促進剤、フィラー、助剤等）：スロット数と項目のカスタマイズ可能
- 硬化剤サブタイプの正規化（amine / polyamide / anhydride / mercaptan / imidazole / DICY / phenolic / latent）
- CSV による高いポータビリティ

### 🔬 物性管理
- 配合ごとの構造化物性入力（DSC/DMA/TMA の Tg、CTE α1/α2、誘電 Dk/Df、熱伝導率、引張せん断、リフロー耐性、PCT/HAST 信頼性等）
- 粘度-温度外挿、多成分系混合粘度

## 🚀 クイックスタート

### 動作環境
- Python **3.10+**
- Windows 10/11、macOS、Linux で動作確認済み

### インストール
```bash
pip install -r requirements.txt
```

### 実行
```bash
python EpoxyManager.py
```

初回起動時、作業ディレクトリに空のデータベースと設定ファイルが自動生成されます。

## 📂 自動生成ファイル（Gitignore 済み）

起動時に作業ディレクトリに以下のファイルが生成されます。**ユーザー固有のデータ**を含むため、デフォルトでバージョン管理から除外されています：

| ファイル | 用途 |
|----------|------|
| `epoxy_db.csv` | 材料データベース |
| `recipe_database.csv` | 配合データベース（物性含む）|
| `custom_properties.csv` | ユーザー定義物性項目 |
| `user_prop_definitions.csv` | ユーザー定義物性カテゴリー |
| `lang_config.json` | 言語設定 |
| `epoxy_prefs.json` | UI 設定（テーマ色、DB パス）|
| `custom_categories.json` | カスタム硬化剤サブタイプ |
| `custom_mat_cats.json` | カスタム材料カテゴリー |
| `mat_col_config.json` | カラム表示設定 |

## 🛠 アーキテクチャ

- **シングルファイル Python アプリケーション**（約 5,670 行）— 外部設定不要、ビルド不要
- **UI**：CustomTkinter + カスタム Apple スタイル widget
- **i18n**：596 キーの単一情報源辞書、zh_TW を標準キーとして CSV 互換性を保持
- **データ**：CSV ストレージ、スキーマ自動マイグレーション搭載
- **ML**：scikit-learn GPR + BayesianRidge + k-NN アンサンブル、物理モデルフォールバック
